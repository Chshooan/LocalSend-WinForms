# LocalSend-WinForms
A Windows LAN file transfer tool based on the LocalSend v2 protocol, built using WinForms and Win32, designed to provide users with a native, fast, and lightweight LocalSend experience on Windows. 一款基于 LocalSend v2 协议 实现的 Windows 局域网文件传输工具，使用 WinForms + Win32 构建，旨在给用户提供 Windows原生、快速、轻量的LocalSend体验。
